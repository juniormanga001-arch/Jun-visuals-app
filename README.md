# JUN VISUALS Web App
Version mobile/PWA connectée au backend Render.

Backend: https://jun-visuals-backend.onrender.com

## Utilisation
Ouvrir `index.html` via un hébergement web HTTPS. Puis Android/Chrome peut proposer l'installation sur l'écran d'accueil.

## Important
Le backend Render gratuit est adapté au prototype. Pour des photos/commandes réellement persistantes, il faudra ensuite ajouter une base de données et un stockage durable.
